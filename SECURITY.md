# Security

If you find a security problem in Drive HUD (for example a way to read someone else's data, or to make the app install something it should not), please **do not open a public issue**.

Report it privately from the [Security tab › Report a vulnerability](https://github.com/V-1per/hud/security/advisories/new). Only the developer sees it. You will get an answer as soon as possible, and the fix goes into the next version.

Only the [latest release](https://github.com/V-1per/hud/releases/latest) and the newest beta get security fixes. Official versions of the app are only published on this repository's [Releases](https://github.com/V-1per/hud/releases) page.
