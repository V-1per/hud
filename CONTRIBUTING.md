# Helping Drive HUD

Thank you for wanting to help! The source code of the app is private, so the most useful help is from people who use it.

## Report a problem
[Open a bug report](https://github.com/V-1per/hud/issues/new?template=bug_report.yml). The more of these the better:
- what you did and what happened instead,
- the app version (Settings › About) and your phone,
- a screenshot or a short video, when you can.

## Suggest an idea
[Open a suggestion](https://github.com/V-1per/hud/issues/new?template=suggestion.yml). Every idea is read; the ones that will be built go to the [roadmap](ROADMAP.md).

## Send a trip recording
Recorded trips help tune the app for every phone and car. Turn on **Settings › Record trip sensors**, drive, and at the end of the trip tap **Send via GitHub**: the form opens filled in, and you attach the file from Downloads. The file is encrypted: only the developer can open it.

## Translations
The app speaks English, Portuguese, Spanish, French, German and Italian. If a text sounds wrong in your language, report it as a problem with the screen where you saw it.

Everyone who helps appears in [COMMUNITY.md](COMMUNITY.md). Please follow the [code of conduct](CODE_OF_CONDUCT.md).
